# EDF WB2 收集手帳

靜態網頁，不需要帳號或資料庫。開啟 `dist/index.html` 即可使用；亦可由一般靜態網站主機提供。

## 專案維護與 GitHub Pages

完整專案保存在此 repo，網站本體位於 `dist/`；目前沒有額外的編譯步驟，修改網頁時直接編輯 `dist/` 內的檔案。

- `server.mjs`：本機預覽伺服器。在 repo 根目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4174/。
- `verify*.mjs`：瀏覽器功能驗證腳本。需先啟動本機伺服器；目前沿用此電腦的 Codex Playwright runtime 路徑與 Microsoft Edge，換電腦時需調整執行環境。
- `normalize-data.mjs`、`inspect_data.py`：資料整理及攻略資料檢查工具。
- `outputs/`：本機截圖、測試備份與 ZIP，已由 `.gitignore` 排除，不納入 Git。
- `.openai/hosting.json`：保留原有 hosting 設定；GitHub Pages 使用下方的 workflow。

GitHub Pages 設定：在 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**，不要選 Deploy from a branch。

`.github/workflows/pages.yml` 會在推送到 `main` 或手動執行 workflow 時，只發布 `dist/` 內容。網站首頁為 https://promise82114.github.io/edfwb2-checklist/ ，網址不包含 `dist`。GitHub Pages 不執行 `server.mjs`，也不會發布測試腳本或工具。

第一次發布需將專案變更 commit 並 push 到 GitHub。後續更新 `dist/` 並推送到 `main`，即可自動部署。由舊本機網址移轉進度時，請先下載 JSON 備份，再到 Pages 網址匯入。

本次整理共 688 項武器、313 項角色版本、207 項配件品質/型別記錄。這是清單項目數，不是遊戲獎盃的分母。

## 使用

- 上方第一排為本篇武器／角色／配件，第二排為 DLC 武器／角色（含特典）。各頁籤直接決定清單範圍，進度與武器 LV 比例分開計算，不再需要完整清單／本篇／DLC 的事後篩選；關卡頁仍保留本篇／EX 範圍及全武器補收對照。既有勾選、收藏與備份沿用相同 ID。
- 各清單日文名稱下方附繁體中文參考翻譯（不是官方中文名稱）。角色版本直接接在名稱後。
- 角色欄顯示隨機救出候選關卡及加入條件；武器附出處角色，滑鼠移入、鍵盤聚焦或點一下可查看關卡提示。
- 搜尋支援中文、日文、出處角色，以及 `M20`／`EX03` 關卡代號。
- 可搜尋、篩選分類、等級或角色版本，以及未取得 / 已取得、本篇 / DLC 特典。
- 武器頁另列 LV1～LV4 收集數與比例（依本篇或 DLC 頁籤分開計算，不隨搜尋篩選改變）；點擊進度卡可切換等級篩選。
- 配件保留品質／型別，另加 LV 欄位及獨立篩選：二手 LV1、全新 LV2、高級 LV3、最強 LV4。
- 配件另列身體／手部／足部／飾品進度卡，點一下篩選、再點一下取消，取代分類下拉。
- 關卡清單列出本篇 M01–104 與 DLC EX01–16；LV 卡沿用武器總進度，選定 LV 後僅列出未取得武器的救出角色。展開關卡可直接勾選武器，支援復原、自動存檔及跨分頁同步。
- 固定候選數以「角色名稱＋版本」計算，由攻略地區／作品／版本分布推算，包含需解鎖或導入角色 DLC／特典的角色，不因武器／角色勾選或 LV 選擇改變。不是已確認的遊戲任務簡報精確人數；M104 未記載，不表示零人。
- 可依補收候選占比或未取得武器數排序，也可只看仍可補收的關卡。候選占比不是掉落機率，武器 LV 難度、金武器解鎖、角色加入條件仍需對照遊戲。
- 點關卡前的 ☆／★ 可加入或取消「我的最愛」；下方獨立區域預設收合角色與缺漏武器資訊，保留候選數與未取得武器數方便比較，需要時再展開，不設內部滾軸。收藏隨 LV／武器進度更新，不受上方搜尋或範圍篩選影響。
- 收藏納入自動存檔、快照、JSON 備份、跨分頁同步與復原；合併備份會聯集收藏，還原新版備份會還原收藏，匯入沒有收藏欄位的舊備份則保留目前收藏。
- DLC 任務包武器分成武器箱、購買附贈及 IMP 累計通關數獎勵；武器箱依 EX 關卡與難度另外列出，不混入救出角色候選。原有裝備加成角色保留在取得方式下方的折疊資訊。
- 勾選立即保存在目前網址的瀏覽器中；按「復原上一步」可取消最近操作。
- 開啟頁面、切換武器／角色／配件及清除篩選時，預設顯示「未取得」，勾選後立即移出待收集清單；仍可手動查看全部或已取得。
- 「備份與還原」可下載 JSON，或合併 / 還原備份。大量更新後請下載備份並存到雲端硬碟。
- 本機自動快照保留最近 12 份，仍會隨瀏覽器資料清除而消失。
- 透過 HTTP 開啟後，離線快取支援再次開啟。直接開 HTML 不使用 service worker。

## 重要界線

清單完成率不是遊戲任務達成度或獎盃判定。配件為額外收集項目；DLC/特典獨立標示，不能把完整清單的分母當成獎盃所需數量。資料依 2026-10-10 讀取的 Wiki 整理，可能受原站缺漏影響。角色逐頁核對版本，武器各名稱/等級分列，配件按品質與資料表列出的型別整理。

沒有雲端同步。手機、電腦、不同瀏覽器或不同網址之間請用備份移轉。保留相同項目 ID，更新清單不會因排序改變而錯配進度。

資料來源：https://w.atwiki.jp/edfwb2/ 。只整理名稱、分類、版本等事實資料，未轉載攻略解說及圖片。每列附原始攻略連結。

救出分布依 https://w.atwiki.jp/edfwb2/pages/71.html 的地區／作品／版本分布推算候選範圍，不保證每次出現，也不等同武器掉落關卡。問號與特殊加入條件保留，M104 分布未記載。此次更新保留全部收集 ID 及存檔格式。

DLC 取得條件依 https://w.atwiki.jp/edfwb2/pages/188.html、https://w.atwiki.jp/edfwb2/pages/14.html 與 https://w.atwiki.jp/edfwb2/pages/21.html 核對。`dist/acquisition.js` 保存稳定 ID 對應的方式、EX 關卡／難度與 IMP 通關數條件；`dist/missions.js` 展開 120 關候選池。特典角色導入後也可救出，不能把購買附贈的 LV1 與後續高階救出武器混為同一來源。
