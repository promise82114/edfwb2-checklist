# EDF WB2 收集手帳

靜態網頁，不需要帳號或資料庫。開啟 `dist/index.html` 即可使用；亦可由一般靜態網站主機提供。

## 專案維護與 GitHub Pages

完整專案保存在此 repo，網站本體位於 `dist/`；目前沒有額外的編譯步驟，修改網頁時直接編輯 `dist/` 內的檔案。

- `server.mjs`：本機預覽伺服器。在 repo 根目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4174/。
- `verify*.mjs`：瀏覽器功能驗證腳本。需先啟動本機伺服器；目前沿用此電腦的 Codex Playwright runtime 路徑與 Microsoft Edge，換電腦時需調整執行環境。
- `normalize-data.mjs`、`inspect_data.py`：資料整理及攻略資料檢查工具。
- `outputs/`：本機截圖、測試備份與 ZIP，已由 `.gitignore` 排除，不納入 Git。
- `.openai/hosting.json`：保留原有 hosting 設定；GitHub Pages 使用下方的 workflow。

GitHub Pages 設定：在 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**，不要選 Deploy from a branch。

`.github/workflows/deploy.yml` 會在推送到 `main` 或手動執行 workflow 時，只發布 `dist/` 內容。網站首頁為 https://promise82114.github.io/edfwb2-checklist/ ，網址不包含 `dist`。GitHub Pages 不執行 `server.mjs`，也不會發布測試腳本或工具。

第一次發布需將專案變更 commit 並 push 到 GitHub。後續更新 `dist/` 並推送到 `main`，即可自動部署。由舊本機網址移轉進度時，請先下載 JSON 備份，再到 Pages 網址匯入。

原始資料共 688 項武器、313 項角色版本、207 項配件品質/型別記錄。排除 3 項獨立特典／免費 DLC 武器後，可顯示武器最多 685 項；未勾選額外內容時為本篇 515 項武器、295 項角色。這是清單項目數，不是遊戲獎盃的分母。

## 使用

- Header 或「備份與還原」提供 Google Drive 連接。連接後預設自動同步，也可關閉自動同步、手動比較或還原；Token 僅存在記憶體，過期後需按重新授權。原有 JSON 備份仍可使用，並支援匯入雲端格式。設定與共用模組文件見 [Google Drive 同步](docs/google-drive-sync.md)。

- 右上方「使用者設定」依已擁有並導入的內容控制清單，預設皆未勾選。季票為父層，連動 13 個角色選項與 1 個追加任務包選項；可個別選取，部分選取顯示半選。第一區不另設分割標題。沒有啟用對應內容時，隱藏 DLC 武器／角色頁籤與進度卡；取消最後一項相關內容時，切回對應本篇清單。
- 「額外購買」只有雙葉理保收藏套組（2 名角色、10 項武器）；「特典」分別勾選本田公關官、姬川公關官、空襲支援兵前輩（各 1 名角色、5 項武器）。
- 教授／上尉／中尉各連動 5 項武器，其餘 10 名 DLC 角色只追加角色。任務包連動 130 項武器（導入附贈 25、EX 武器箱 80、IMP 累計通關獎勵 25）與 EX01–16。
- 角色清單、武器清單、進度分母、LV 統計、關卡候選數、補收對照、關卡搜尋與收藏顯示都依設定更新。取消設定只隱藏內容，保留取得進度與 EX 收藏。
- 設定納入自動儲存、跨分頁同步、復原、快照與 JSON 備份。合併備份聯集已勾選設定；還原新版備份套用備份設定，沒有設定欄位的舊備份保留目前設定。
- 排除リクルート殺虫スプレー、リクルートスティングレイ、リクルートレーザーチェーンソー；原始資料與穩定 ID 保留以兼容舊備份。`dist/content.js` 保存內容需求映射，`verify-content.mjs` 驗證設定與清單連動。

- 上方第一排為本篇武器／角色／配件，第二排為 DLC 武器／角色（含特典）。各頁籤直接決定清單範圍，進度與武器 LV 比例分開計算，不再需要完整清單／本篇／DLC 的事後篩選；關卡頁仍保留本篇／EX 範圍及全武器補收對照。既有勾選、收藏與備份沿用相同 ID。
- 各清單日文名稱下方附繁體中文參考翻譯（不是官方中文名稱）。角色版本直接接在名稱後。
- 角色欄顯示隨機救出候選關卡及加入條件；武器附出處角色，滑鼠移入、鍵盤聚焦或點一下可查看關卡提示。
- 搜尋支援中文、日文、出處角色，以及 `M20`／`EX03` 關卡代號。
- 可搜尋、篩選分類、等級或角色版本，以及未取得 / 已取得、本篇 / DLC 特典。
- 武器頁另列 LV1～LV4 收集數與比例（依本篇或 DLC 頁籤分開計算，不隨搜尋篩選改變）；點擊進度卡可切換等級篩選。
- 配件保留品質／型別，另加 LV 欄位及獨立篩選：二手 LV1、全新 LV2、高級 LV3、最強 LV4。
- 配件另列身體／手部／足部／飾品進度卡，點一下篩選、再點一下取消，取代分類下拉。
- 關卡清單列出本篇 M01–104，勾選追加任務包後才加入 EX01–16；上方提供武器LV1～LV4 與角色共五個補收模式。武器模式每把未取得武器只列一張小卡，底下合併該關相關角色與版本；角色模式只列尚未取得的候選角色。展開關卡可直接勾選武器，支援復原、自動存檔及跨分頁同步。
- 候選角色數量以「角色名稱＋版本」計算，由攻略地區／作品／版本分布推算，包含已於使用者設定啟用的 DLC／特典角色，不因取得勾選或 LV 選擇改變，但會隨 DLC 設定更新。不是已確認的遊戲任務簡報精確人數；M99–102 與 M104 無救出角色，候選數為 0；最後一組有角色的關卡為 M96–98、M103。
- 可依補收候選占比或未取得武器數排序，也可只看仍可補收的關卡。候選占比不是掉落機率，武器 LV 難度、金武器解鎖、角色加入條件仍需對照遊戲。
- 點關卡前的 ☆／★ 可加入或取消「我的最愛」；「關卡清單」內提供「原始關卡清單／推薦關卡／我的最愛」三個頁籤，關卡表格隨整頁向下捲動，不設內部滾軸。收藏預設收合角色與缺漏武器資訊，保留候選數與未取得武器數方便比較，需要時再展開。收藏隨武器 LV／角色模式及收集進度更新，不受上方搜尋或範圍篩選影響。
- 關卡列表新增「重點查看」開關，原始／推薦／我的最愛共用；武器模式啟用後直接條列「角色：尚未取得武器」，合併同名角色的 α／β／γ，附中日名稱供進關前確認。已取得角色仍可列為缺武器的救援目標，武器箱另列；取消勾選回到原有可展開的小卡。角色補收模式保留原版面。
- 推薦關卡依 2026-10-18 核對的 Wiki「稼ぎミッション（ブラザー救出編）」整理，包含 35 個獨立介紹的任務與 M58 內提及的 M63，共 36 關；不將整段候選範圍或其他章節的任務一律列為推薦。各關保留候選數、補收武器／角色，另列簡短推薦原因及條件；可共用搜尋、範圍、排序、只看仍可補收與五種補收模式。
- 我的最愛新增每關筆記（最多 5000 字），輸入即存檔，支援復原、重開、跨分頁及 Google Drive 同步，筆記自動增高。取消收藏或停用 DLC 仍保留筆記，再加入收藏或啟用內容即可繼續編輯。筆記納入快照與 JSON 備份；合併以更新時間較新的筆記為準，還原新版備份會套用筆記（含清空），舊備份沒有筆記欄位時保留目前筆記。
- 收藏納入自動存檔、快照、JSON 備份、跨分頁同步與復原；合併備份會聯集收藏，還原新版備份會還原收藏，匯入沒有收藏欄位的舊備份則保留目前收藏。
- DLC 任務包武器分成武器箱、購買附贈及 IMP 累計通關數獎勵；武器箱依 EX 關卡與難度另外列出，不混入救出角色候選。原有裝備加成角色保留在取得方式下方的折疊資訊。
- 勾選立即保存在目前網址的瀏覽器中；按「復原上一步」可取消最近操作。
- 開啟頁面、切換武器／角色／配件及清除篩選時，預設顯示「未取得」，勾選後立即移出待收集清單；仍可手動查看全部或已取得。
- 「備份與還原」可下載 JSON，或合併 / 還原備份。大量更新後請下載備份並存到雲端硬碟。
- 本機自動快照保留最近 12 份，仍會隨瀏覽器資料清除而消失。
- 透過 HTTP 開啟後，離線快取支援再次開啟。直接開 HTML 不使用 service worker。

## 重要界線

清單完成率不是遊戲任務達成度或獎盃判定。配件為額外收集項目；DLC/特典獨立標示，不能把完整清單的分母當成獎盃所需數量。資料依 2026-10-10 讀取的 Wiki 整理，可能受原站缺漏影響。角色逐頁核對版本，武器各名稱/等級分列，配件按品質與資料表列出的型別整理。

Google Drive 連接後預設自動同步：停止操作 5 秒後同步，每 60 秒、恢復連線與回到頁面時再次檢查；內容一致時不重複上傳。每項取得、收藏、筆記及設定以較新的更新時間為準（同時間保留本機），取消操作也會同步。多裝置的時鐘應保持正確。雲端版本衝突會重新讀取並重試，無法驗證的資料會暫停同步。本機套用雲端變更前會保留快照。授權僅保留在頁面記憶體，過期或重新整理後需按一下重新連接；未連接仍使用原有本機儲存。手機、電腦、不同瀏覽器或不同網址之間，可透過雲端進度或 JSON 備份移轉。保留相同項目 ID，更新清單不會因排序改變而錯配進度。

資料來源：https://w.atwiki.jp/edfwb2/ 。整理名稱、分類、版本等事實資料及簡短刷關摘要，完整攻略與圖片請至來源閱讀。每列附原始攻略連結。

救出分布依 https://w.atwiki.jp/edfwb2/pages/71.html 的地區／作品／版本分布推算候選範圍，不保證每次出現，也不等同武器掉落關卡。問號與特殊加入條件保留；M96–98 與 M103 沿用最後一組候選分布，M99–102 與 M104 明確標示無救出角色。此次更新保留全部收集 ID 及存檔格式。

DLC 取得條件依 https://w.atwiki.jp/edfwb2/pages/188.html、https://w.atwiki.jp/edfwb2/pages/14.html 與 https://w.atwiki.jp/edfwb2/pages/21.html 核對。`dist/acquisition.js` 保存稳定 ID 對應的方式、EX 關卡／難度與 IMP 通關數條件；`dist/missions.js` 展開 120 關候選池。特典角色導入後也可救出，不能把購買附贈的 LV1 與後續高階救出武器混為同一來源。

關卡五種補收模式可執行 `node verify-mission-modes.mjs` 驗證，涵蓋武器去重、角色取得／復原、DLC 候選數增減、收藏、搜尋、無角色關卡與手機版面。

武器小卡下方的相關角色版本可獨立勾選，勾武器不推定取得任何角色。剛勾選的救出武器在已展開的關卡／收藏區暫時保留，收合或切換模式後移除；暫留僅為畫面狀態，不影響缺漏統計，也不寫入備份。`node verify-linked-collection.mjs` 驗證兩種取得狀態、角色版本、暫留、收藏同步與復原。

頁籤與筆記可執行 `node verify-mission-tabs.mjs` 驗證，涵蓋 36 關完整名單、推薦原因搜尋、補收連動、筆記輸入／清空／復原、重開、跨分頁、備份合併／還原／舊版兼容、雲端資料合併、鍵盤頁籤與手機無內部捲動。`verify-cloud.mjs` 另以模擬 Google Drive 驗證只有筆記更新時也會上傳，以及其他裝置清空筆記後能同步。
